# AFTERHOURS

A first-person psychological horror game for Windows, built with Godot 4.3.

## Run
Open the repository in Godot 4.3 or newer and press F6/F5. The project uses the Compatibility renderer.

## Controls
WASD move · Mouse look · Shift sprint · Ctrl crouch · E interact · F flashlight · Tab objectives · Esc pause. The flashlight drains while active and recharges while switched off.

## Windows build
Push to main or run the Windows Build workflow manually. The exported Windows application is published as the AFTERHOURS-Windows Actions artifact. Version tags beginning with v also publish a GitHub Release.

## Current build
The project includes a procedural mall environment, first-person movement, interaction framework, CCTV camera rendering, timed shift, evidence collection, a stalking anomaly, procedural ambience and footsteps, flashlight battery, CCTV, story events, pause/menu UI, save/load, and multiple ending variations. This is an active development build, not a finished full six-hour commercial release.
